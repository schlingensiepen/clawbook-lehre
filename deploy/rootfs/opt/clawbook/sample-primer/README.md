# primer — dein erstes Projekt in clawbook

Dieses Beispielprojekt liegt unter `~/source/Sample/primer`.
Projekte in clawbook folgen dem Schema
`~/source/<Thema>/<Projekt>` — so legt sie auch der
WorkspaceManager (`wsm`) an; jedes Projekt ist ein eigenes
Git-Repository.

Hier kannst du gefahrlos ausprobieren:

- in VS Code den Ordner öffnen und Dateien bearbeiten,
- im Terminal `cd ~/source/Sample/primer` und dann einen
  Agenten starten, z. B. `claude`, `codex` oder `copilot`,
- mit `git status` und `git log` sehen, was sich geändert
  hat.

Wenn du das Projekt nicht mehr brauchst, darfst du den
Ordner löschen; clawbook legt ihn nicht neu an.
